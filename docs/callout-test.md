# Callout Test Page

This page demonstrates the different types of callouts.

> [!note]
> This is a note callout. It provides additional information.

> [!abstract]
> This is an abstract callout. It summarizes content.

> [!info]
> This is an info callout. It provides helpful information.

> [!todo]
> This is a todo callout. It lists tasks to be completed.

> [!tip]
> This is a tip callout. It offers helpful advice.

> [!success]
> This is a success callout. It indicates something was completed successfully.

> [!question]
> This is a question callout. It poses a question to the reader.

> [!warning]
> This is a warning callout. It warns about potential issues.

> [!failure]
> This is a failure callout. It indicates something didn't work.

> [!danger]
> This is a danger callout. It warns about serious issues.

> [!bug]
> This is a bug callout. It highlights a bug or issue.

> [!example]
> This is an example callout. It provides an example.

> [!quote]
> This is a quote callout. It contains a quotation.
